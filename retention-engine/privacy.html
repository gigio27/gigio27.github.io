Privacy policy

retention-engine · last updated 8 November 2026

Who uses it

retention-engine is a private tool run by one person for their own YouTube channel. The only Google account that authorizes it is the operator's own. It is not offered to the public.

What it accesses

Through Google OAuth, the tool requests these scopes on the operator's account:

  • youtube.readonly: read the channel's own videos and their statistics.
  • yt-analytics.readonly: read the channel's YouTube Analytics reports, such as views, watch time and audience retention.
  • youtube.upload: upload the videos the tool produces to the channel.
  • youtube.force-ssl: update the titles, descriptions, thumbnails and caption tracks of the channel's own videos, and post comments on them.

How it is used

Only to publish the channel's own videos and to measure how they perform. Google user data is never sold, never used for advertising, and never used to train AI models.

To analyse performance, the channel's analytics may be processed by AI model providers acting on the operator's behalf, solely to produce that analysis for the operator.

Where it is stored

On the operator's own computers: the OAuth token in a local configuration file, and the analytics in a local database. Nothing is shared with anyone else.

Google API Services

retention-engine's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

The tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time from myaccount.google.com/permissions. Local data is deleted by the operator.
